**Висновки**
- Усі класи проходять фінальну печеру на її рівні без смертей. Найшвидші — Перунів жрець і Самопальник (дальній бій), найповільніший — Знахар (підтримка).
- Волхви отримують помітно менше шкоди, ніж козаки: бот тримає дистанцію. Це природна різниця між магом і воїном; у козаків за це більше здоров'я (+30…60%) і шкоди.
- Єдине місце зі смертями на своєму рівні — Брянські ліси для Козака (~20% на 12 рівні): місцевість стартує з «чорною» заразою. Залишено як небезпечну зону.
- Бот не п'є зілля й не користується блоком/парируванням — живий гравець виживає краще.
