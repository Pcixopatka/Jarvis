# Підказки до анкет Play Console

Відповіді нижче чинні для нинішньої збірки: без інтернету, без реклами сторонніх мереж, без покупок. Якщо підключиш рекламу чи покупки, анкети «Безпека даних» і «Реклама» доведеться заповнити наново.

## Безпека даних

| Запитання | Відповідь |
|---|---|
| Чи збирає або передає застосунок дані користувачів? | Ні |
| Чи шифруються дані під час передавання? | Не застосовується: гра нічого не передає |
| Чи може користувач попросити видалити дані? | Не застосовується: даних на серверах немає, збереження видаляються разом із грою |

Чому так: у маніфесті немає жодного дозволу, зокрема доступу до мережі. Збереження лежать у приватній пам'яті застосунку. Перенесення збереження йде через буфер обміну лише з ініціативи гравця.

## Віковий рейтинг (анкета IARC)

Анкету заповнюєш сам, вона коротка. Ось факти про гру, які в ній спитають.

| Тема | Що є в грі |
|---|---|
| Насильство | Бої з нечистю й зараженими людьми в піксельній графіці. Ворог падає й зникає. Є стан «кровотеча» з червоними бризками, розчленування й натуралізму немає |
| Страх | Нечисть із фольклору: упирі, чорти, Вій. Без різких лякалок |
| Азартні ігри | Кості в шинку на ігрові гривні. Справжніх грошей і призів немає |
| Алкоголь, тютюн | Шинок як місце дії, хміль на городі як товар. Пиття й куріння не показано |
| Лайка | Немає |
| Сексуальний вміст | Немає |
| Спілкування гравців, обмін вмістом | Немає |
| Передавання місцезнаходження | Немає |
| Покупки | Немає |
| Політичні теми | Див. пункт 4 у `README.md` |

## Реклама

Зараз: «Ні, застосунок не містить реклами». Заглушку «реклами спонсора» до публікації треба або замінити справжньою мережею, або перейменувати (пункт 1 у `README.md`).

## Цільова аудиторія

Радимо 13+ або 16+. Якщо позначити вік до 13 років, гра потрапляє під правила для дитячих застосунків, а вони суворіші.

## Доступ до застосунку

Уся гра доступна без входу й без особливих умов. Інструкцій для перевірки не потрібно.
