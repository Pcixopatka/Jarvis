# Тести

Потрібен Godot 4.3 у PATH (або вкажіть шлях до нього).

```bash
godot --headless --import                                      # один раз після клонування
godot --headless --path . -s res://tests/check_scripts.gd       # компіляція всіх скриптів
godot --headless --path . -s res://tests/run_tests.gd --fixed-fps 60
TEST_VERBOSE=1 godot --headless --path . -s res://tests/run_tests.gd --fixed-fps 60   # з деталями сценарію
```

Код виходу `0` означає, що все гаразд, `1` — є провалені перевірки (їх видно в журналі з позначкою ✗).
Тести не чіпають справжнє збереження гравця, бо пишуть в окремий файл `user://test_hero.save`.

| Набір | Що перевіряє |
|---|---|
| Дані | Узгодженість локацій, ворогів, вмінь і перків; генерацію речей усіх слотів і рідкостей; генерацію завдань |
| Козак | Рівні й очки, вивчення всіх вмінь і перків, межі показників, спорядження, заточку, серіалізацію |
| Збереження | Запис і читання, відновлення з резервної копії після пошкодження, міграцію v2 → v3, відхилення невідомих версій |
| Місто | Крамницю, купівлю й продаж, найм і обмеження загону, здачу завдань |
| Сценарій гри | Бот у справжній сцені: нова гра → завдання → зачистка Дикого Поля → Змієва печера з босом → здача завдань → крамниця, коваль, корчма → екран козака → збереження й завантаження → похід із супутником → смерть і повернення в місто |
| Активності | Правила й гру для кожного з одинадцяти занять: герць, розшук, варта, торгівля, полювання й рибалка, шинок, сліди, город, походи супутників, рекорди роду, сезонні свята |

Свята за календарем у тестах вимкнено (`HolidayService.forced = "none"`), а час задається через `ChallengeService.now_override`, тож набір проходить однаково будь-якого дня.

На GitHub тести запускаються автоматично при кожному пуші (`.github/workflows/tests.yml`). Помилка скрипту посеред набору обриває його без проваленої перевірки, тому CI окремо шукає в журналі `SCRIPT ERROR` і падає, якщо знайде.
