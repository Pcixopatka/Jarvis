# Тести

Потрібен Godot 4.7.1 у PATH (або вкажіть шлях до нього).

```bash
godot --headless --import                                      # один раз після клонування
godot --headless --path . -s res://tests/check_scripts.gd       # компіляція всіх скриптів
godot --headless --path . -s res://tests/run_tests.gd --fixed-fps 60
TEST_VERBOSE=1 godot --headless --path . -s res://tests/run_tests.gd --fixed-fps 60   # з деталями сценарію
```

Код виходу `0` означає, що все гаразд, `1` — є провалені перевірки (їх видно в журналі з позначкою ✗).
Тести не чіпають справжнє збереження гравця, бо пишуть в окремий файл `user://test_hero.save`.

| Набір | Що перевіряє |
|---|---|
| Дані | Узгодженість локацій, ворогів, вмінь і перків; генерацію речей усіх слотів і рідкостей; генерацію завдань |
| База даних | `data/*.json` через `GameDB`: `problems()` порожній, цілі поля цілі, записи заморожені, невідомий id, номери записів, кожна нечисть стає до бою, перевірка ловить зламаний запис; посилання на механіки ведуть на файли, сиріт нема, хибне посилання впіймано |
| База світу | Краї, міста, місця, землі, краєвиди й властивості еліт у `data/*.json`: кількість, порядок, сталі номери, позиції `Vector2` і цілі поля, записи заморожені й без копій, файли в єдиному вигляді; зламаний запис кожної таблиці впіймано |
| База класів і вмінь | Класи, ступені майстерності, вузли дерев, ключі бонусів, Загартування, характеристики, звитяги й картки доріг у `data/*.json`: кількість, порядок, сталі номери, типи (числа на ранзі, кольори), правила майстерності в записі класу, записи заморожені й без копій, той самий id у кількох класах, файли в єдиному вигляді; зламаний запис кожної таблиці впіймано |
| Бій у кожному місці | У кожному з місць мапи починається справжній бій: нечисть місця, земля й шум його краєвиду |
| Кожен клас уживає свої вміння | Кожен клас вивчає всю свою дорогу за правилами дерева й у справжньому бою вживає кожне активне вміння дороги |
| Механіки нечисті | Кожна механіка (звичайна форма й бос, до й після люті) у справжньому бою робить свій прийом і постріл; заражений лишає одну хмару |
| Козак | Рівні й очки, вивчення всіх вмінь і перків, межі показників, спорядження, заточку, серіалізацію |
| Збереження | Запис і читання, відновлення з резервної копії після пошкодження, міграцію v2 → v3, відхилення невідомих версій |
| Місто | Крамницю, купівлю й продаж, найм і обмеження загону, здачу завдань |
| Сценарій гри | Бот у справжній сцені: нова гра → завдання → зачистка Дикого Поля → Змієва печера з босом → здача завдань → крамниця, коваль, корчма → екран козака → збереження й завантаження → похід із супутником → смерть і повернення в місто |
| Активності | Правила й гру для кожного з дванадцяти занять: герць, розшук, варта, торгівля, полювання й рибалка, шинок, сліди, город, походи супутників, рекорди роду, сезонні свята |
| Звук, зілля наснаги, боси | Наявність усіх записів і мелодій, правила зілля, бої з Відьмою й Вієм |
| Супровід | Завдання на дошці, бій із мандрівником, засідки, перемога, поразка й смерть героя |
| Безпечна зона й «Назад» | Відступи під виріз камери, кроки системної кнопки «Назад» на кожному екрані |
| Перенесення роду | Код: цілий, розрізаний, зіпсований, чужий; заміна й повернення роду у файлах і в грі |
| Клейноди роду | Ціни й бонуси всіх семи клейнодів, спільність на рід, збереження, вкладку на хуторі, камені в скарбника, заточку без ризику в місті й на хуторі, прокрутку списку після покупки |
| Виклики | Чотири денні й три тижневі, по два про події; лише відкрите; подія, супровід, сліди й облога на вимогу виклику; перескладання після оновлення |
| Коло Кожум'яки й огляд | Склад тижня, сила чудовиськ і сотень відносно героя, нагороди, рекорди, бій із трьома чудовиськами й сутичка ватаг із побратимами |
| Далекі краї | Чотири краї, нова нечисть і боси, рівень, що росте з героєм, надбавка до досвіду, темп юрби, завдання й події для бувалих, мапа |
| Список подій і довідник | Стан кожної події для селянина й бувалого козака, «зараз на мапі», повнота довідника (уся нечисть, боси, місця, класи, свята), пошук, кнопки й «Назад» |
| Куди пускають | Межі правила (поле — до трьох рівнів вище за героя, печера з босом — з її рівня, місто завжди, свої замки Башти, Глибин і надважких печер); крок із босом рівня печери й місце кожної місії відкрите з її рівня, перевірка даних ловить порушення; `Game.enter_location` відмовляє, мапа малює закрите як закрите місце занять, тексти панелі; сірі завдання, супровід і розшук із «Ще зарано», відмова наставника, мовчазний побратим; крамниця на рівні героя; події лише у відкритих місцях; узяте раніше пускає у своє місце; швидкий похід, «Шлях козака», порадник; довідник |
| Майстерність: вища стеля, рання зміна класу | Межі майстерності в записах класів (Селянин 20 і далі з 10-ї, перший клас 50 і далі з 40-ї, спеціалізація 50); рання зміна класу лишає без очок за решту рівнів, і ні Камінь забуття, ні Алатир-камінь їх не вертають; зайві очки терплячого Селянина йдуть у дерево Козака; вікно попередження перед присягою й посвятою нижче вершини («Ні», «Назад», «Так») і без нього на вершині; підказка про нову дорогу лише раз; екран героя; міграція v13 (слоти, файл без слота, раз, із банером; новий герой нічого не дістає); довідник |

Свята за календарем у тестах вимкнено (`HolidayService.forced = "none"`), а час задається через `ChallengeService.now_override`, тож набір проходить однаково будь-якого дня. Звук і музику з налаштувань пристрою (`user://settings.cfg`) на час прогону ввімкнено, а наприкінці повернуто як були: перевірки звуку не залежать від того, що там лишилось.

На GitHub тести запускаються автоматично при кожному пуші (`.github/workflows/tests.yml`). Помилка скрипту посеред набору обриває його без проваленої перевірки, тому CI окремо шукає в журналі `SCRIPT ERROR` і падає, якщо знайде.
